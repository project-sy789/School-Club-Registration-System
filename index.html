ค้นหาและตรวจสอบผลการลงทะเบียน

คุณสามารถค้นหาประวัติการลงทะเบียนได้โดยระบุ เลขประจำตัวนักเรียน หรือ ชื่อ-นามสกุล ของนักเรียน

เลขประจำตัว ชื่อ - นามสกุล ห้องเรียน ชุมนุมที่ลงทะเบียน ครูผู้ดูแล สถานะการลงทะเบียน วันเวลาที่ลงทะเบียน

สถานะแต่ละชุมนุมและการจองที่นั่ง

ชื่อชุมนุม ครูผู้สอน ระดับชั้นที่รับ จำนวนรับ สมัครแล้ว (เดิม / ใหม่) ความหนาแน่น การจัดการ

ตรวจสอบการสมัครของนักเรียนใหม่ / ไม่มีชื่อในระบบ

นักเรียนที่กรอกข้อมูลเองเพื่อสำรองสิทธิ์ (Pending) สามารถตรวจยืนยันสิทธิ์หรือแก้ไขข้อมูลได้ที่นี่

ชื่อ-นามสกุล ระดับชั้น/ห้อง ชุมนุมที่จอง เลขประจำตัวที่กรอก วันที่สมัคร การตรวจสอบและอนุมัติ

จัดการข้อมูลชุมนุมและโควตา

คุณสามารถเพิ่ม ลบ หรือแก้ไขข้อมูลชุมนุมที่มีอยู่ได้ที่นี่ หรือนำเข้าด้วยไฟล์ CSV (คอลัมน์: name, teacher, location, capacity, description, grades)

ชื่อชุมนุม ครูผู้ดูแล สถานที่เรียน ระดับชั้น จำนวนรับ คำอธิบาย ตัวเลือก

นำเข้าฐานข้อมูลนักเรียนที่มีอยู่แล้ว

อัปโหลดไฟล์ Excel/CSV ข้อมูลนักเรียนเดิมเพื่อใช้ในการดึงข้อมูลอัตโนมัติและตรวจสอบสิทธิ์

ลากไฟล์ .csv หรือ .xlsx มาวางที่นี่ หรือคลิกเพื่ออัปโหลด

ยินดีต้อนรับสู่ระบบสำเร็จรูป! กรุณาระบุรหัส API ของโครงการ Supabase ของคุณเพื่อเชื่อมต่อฐานข้อมูลและทำงานได้สมบูรณ์ในทันที

วิธีการรับค่า API ในโครงการ Supabase:
  1. เปิดหน้า Dashboard ของ Supabase แล้วกดสร้าง Project ใหม่
  2. เข้าไปที่เมนู Settings > API
  3. คัดลอกค่า Project URL และ anon (public) Key มาใส่ในช่องด้านบน
  4. กดปุ่มบันทึก ระบบจะจำค่าเชื่อมต่อไว้ในบราวเซอร์นี้โดยอัตโนมัติ!
