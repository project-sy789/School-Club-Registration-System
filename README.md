# 🏫 ระบบลงทะเบียนเรียนชุมนุมนักเรียนระดับมัธยม (School Club Registration System)

ระบบลงทะเบียนเลือกชุมนุมสำหรับนักเรียนระดับมัธยมศึกษาตอนต้นและตอนปลาย สำเร็จรูปสไตล์พรีเมียม พัฒนาด้วยเทคโนโลยีแบบ **Single Page Application (SPA)** ที่ทำงานได้รวดเร็วเป็นพิเศษบนเครื่องคอมพิวเตอร์และโทรศัพท์มือถือ โดยมีหลังบ้านเป็น **Supabase** ฟรีทีวี (Free Tier) ที่รองรับนักเรียนลงทะเบียนพร้อมกันกว่า **800 คน** ได้อย่างไร้รอยต่อ โดยไม่เกินข้อจำกัดการเชื่อมต่อ (Connection limits) และไม่เกิดการจองที่นั่งซ้ำซ้อน (Race Condition) 

---

## 🎨 จุดเด่นของระบบ (Key Features)

* **ดีไซน์พรีเมียมสีเขียวเอมเมอรัลด์ (Premium Emerald Glassmorphism):** หน้าเว็บตอบสนองรวดเร็ว ลื่นไหล มีเอฟเฟกต์สะท้อนแสง ทรานซิชันสวยงาม และรองรับการแสดงผลแบบ Responsive ในมือถือ 100%
* **ระบบตัวจับเวลาเปิด-ปิดอัตโนมัติ (Dynamic Live Countdown):** แสดงผลเวลาเปิดรับสมัครนับถอยหลังระดับมิลลิวินาที และเปิด/ปิดระบบให้ลงทะเบียนได้โดยอัตโนมัติโดยที่นักเรียนไม่ต้องกดรีเฟรชหน้าเว็บ
* **ระบบตัดยอดที่นั่งปลอดภัยสูงสุด (Row Lock Atomic Seats):** ใช้ฟังก์ชัน Stored Procedure บน PostgreSQL (`FOR UPDATE`) ในการล็อกที่นั่งก่อนเขียนทับ ทำให้มั่นใจว่าไม่มีทางเกิดปัญหา "ที่นั่งเรียนเกินโควตา" แม้จะยิงจองเข้ามาพร้อมกันในเสี้ยววินาทีเดียวกัน
* **ระบบสำรองสิทธิ์กรณีไม่มีชื่อ/เด็กใหม่ (Hybrid Verification Flow):** สำหรับนักเรียนที่ย้ายมาใหม่หรือไม่มีชื่อในระบบชั่วคราว สามารถพิมพ์ชื่อเลือกห้องเพื่อสำรองสิทธิ์จองที่นั่งได้ทันที (สถานะ Pending) เพื่อไม่ให้เด็กเสียสิทธิ์ และคุณครูสามารถตรวจสอบอนุมัติในภายหลังได้
* **ตัวช่วยติดตั้งแบบ 5 นาทีสำเร็จ (Guided WordPress-style Installer):** หากเปิดใช้งานครั้งแรกและยังไม่ได้ตั้งค่า API ของ Supabase ระบบจะมีหน้าต่าง Setup Overlay สีเขียวสวยงามให้ครูกรอกเพื่อจำไว้ในบราวเซอร์ทันทีโดยไม่ต้องไปแตะต้องไฟล์โค้ดใด ๆ
* **ระบบผู้ดูแลระบบอัจฉริยะ (Admin Dashboard):**
  * **รายงานสรุปเรียลไทม์:** รายงานสัดส่วนการจอง สถิติจำนวนที่นั่งของแต่ละชุมนุม
  * **ระบบอนุมัติเด็กใหม่:** แสดงตารางจัดการเด็กสมัครใหม่พร้อมระบบยืนยันตัวตนหรือสลับยกเลิกสิทธิ์
  * **จัดการชุมนุม:** ฟอร์มเพิ่ม ลบ หรือแก้ไขรายละเอียดชุมนุม ครูผู้สอน สถานที่เรียน โควตา และช่วงชั้นที่รับสมัคร (ม.1 - ม.6)
  * **ระบบ Bulk Import รายชื่อเด็ก:** นำเข้ารายชื่อนักเรียนเก่าได้เพียงลากและวางไฟล์ `.csv` ประมวลผลรวดเร็วผ่านคำสั่ง Upsert Batch
  * **ส่งออกเอกสาร Excel (Thai BOM CSV Export):** ส่งออกรายชื่อนักเรียนแยกตามชุมนุมหรือรวมทั้งโรงเรียนเป็นไฟล์ CSV ที่รองรับอักษรไทยสมบูรณ์แบบ เปิดใน Excel ภาษาไม่เพี้ยน ไม่เป็นตัวต่างดาว

## 📂 โครงสร้างไฟล์ในโปรเจกต์ (File Structure)

```text
├── index.html          # โครงสร้างหน้าเว็บหลักของระบบ (Student Portal & Admin Dashboard & Setup overlay)
├── style.css           # สไตล์ชีทตกแต่งธีมเขียวพรีเมียม ดีไซน์โปร่งแสง (Glassmorphism) และปุ่มสลับต่างๆ
├── app.js              # ชุดคำสั่งควบคุมหน้าบ้าน การหน่วงเวลา Jitter, การจัดการแท็บ และการเชื่อมต่อ Supabase
├── config.js           # ไฟล์สำหรับเก็บค่ากำหนด API เพื่อให้เครื่องของทุกคนดึงไปใช้โดยไม่ต้องผ่านฟอร์มตั้งค่า
└── supabase/
    └── setup_database.sql  # สคริปต์ SQL ทั้งหมดสำหรับใช้ตั้งค่าใน Supabase SQL Editor
```

## 🚀 ขั้นตอนการติดตั้งและตั้งค่าระบบ (Installation & Setup)

คุณสามารถติดตั้งระบบนี้ใช้งานได้ฟรีผ่าน **Supabase Free Tier** ตามขั้นตอนง่าย ๆ ดังนี้:

### ขั้นตอนที่ 1: ตั้งค่าฐานข้อมูลบน Supabase
1. สมัครสมาชิกหรือลงชื่อเข้าใช้งานที่ [Supabase](https://supabase.com)
2. กดปุ่ม **Create a new project** ตั้งชื่อโครงการและรหัสผ่านฐานข้อมูลให้เรียบร้อย (เลือก Region เป็น Singapore เพื่อการตอบสนองที่รวดเร็วที่สุดในไทย)
3. เมื่อสร้างโปรเจกต์เสร็จสิ้นแล้ว ให้ไปที่แท็บเมนู **SQL Editor** (สัญลักษณ์ `SQL` บนแถบควบคุมด้านซ้ายมือ)
4. คลิกปุ่ม **New Query**
5. คัดลอกเนื้อหาทั้งหมดจากไฟล์ [supabase/setup_database.sql](supabase/setup_database.sql) ไปวางลงในช่อง SQL Editor แล้วกดปุ่ม **Run** (สัญลักษณ์ปุ่มสีเขียวขวาล่าง)
6. เมื่อสคริปต์ทำงานเสร็จสิ้น ฐานข้อมูล ตาราง เงื่อนไขความปลอดภัย (RLS) และฟังก์ชัน Stored Procedure ต่าง ๆ จะถูกสร้างขึ้นพร้อมสำหรับเข้าทำงานทันที!

### ขั้นตอนที่ 2: ตั้งค่าหน้าเว็บเพื่อเชื่อมต่อ API
คุณเลือกตั้งค่าได้ **2 วิธี** ตามความสะดวก:

#### วิธีที่ 1: ตั้งค่าถาวรผ่านไฟล์โค้ด (แนะนำสำหรับใช้แจกจ่ายให้นักเรียน)
1. เปิดไฟล์ [config.js](config.js) ในโปรแกรมแก้ไขข้อความ
2. นำค่า **Project URL** และ **anon (public) Key** จากหน้าโครงการ Supabase ของคุณ (หาได้จากเมนู **Settings** > **API**) มาใส่ในช่องที่กำหนด:
   ```javascript
   const SUPABASE_CONFIG = {
       SUPABASE_URL: "https://your-project-id.supabase.co", 
       SUPABASE_ANON_KEY: "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpX..." 
   };
   ```
3. บันทึกไฟล์ หน้าเว็บจะถูกเชื่อมต่อไปยังฐานข้อมูลหลักของคุณโดยอัตโนมัติ

#### วิธีที่ 2: ตั้งค่าผ่านหน้าจอบราวเซอร์ (WordPress-style Setup)
1. เมื่อเปิดเข้าหน้าเว็บ [index.html](index.html) เป็นครั้งแรก บราวเซอร์จะขึ้นหน้าต่าง **"การตั้งค่าใช้งานครั้งแรก"** สีเขียว
2. คัดลอกค่า **Supabase URL** และ **anon (public) Key** จาก Supabase มากรอกใส่ช่องที่ปรากฏบนหน้าจอ
3. กดปุ่ม **"บันทึกค่าเชื่อมต่อและเข้าสู่เว็บ"**
4. ระบบจะจดจำค่าเชื่อมต่อและบันทึกลงในบราวเซอร์ของคุณอย่างปลอดภัย พร้อมรีโหลดเพื่อเริ่มทำงานทันที!

## 🔒 ข้อมูลความปลอดภัยของระบบผู้ดูแลระบบ (Admin Access)
* รหัสผ่านเริ่มต้นสำหรับเข้าสู่ระบบผู้ดูแลระบบคือ: **`admin-password-1234`**
* คุณครูสามารถเข้าไปแก้ไขรหัสผ่านควบคุมนี้ รวมถึงชื่อโรงเรียน ปีการศึกษา และกำหนด วัน-เวลา เปิดปิดระบบสมัครเรียนแบบล่วงหน้าได้ที่แท็บ **"ตั้งค่าเปิด-ปิดระบบ"** ในหน้าผู้ดูแลระบบโดยตรง

## 💻 การทดสอบรันภายในเครื่อง (Local Run)
คุณสามารถรันโปรเจกต์นี้ในเครื่องคอมพิวเตอร์ของคุณเพื่อทดสอบก่อนการ Deploy ได้ง่าย ๆ:

**ใช้ Python (แนะนำสำหรับ macOS/Windows):**
เปิด Terminal ในโฟลเดอร์โปรเจกต์และรันคำสั่ง:
```bash
python3 -m http.server 8080
```
จากนั้นเปิดบราวเซอร์และไปที่ `http://localhost:8080` เพื่อเข้าใช้งาน!
