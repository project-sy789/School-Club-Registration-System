# 🏫 ระบบลงทะเบียนเรียนชุมนุมนักเรียนระดับมัธยม (School Club Registration System)

ระบบลงทะเบียนเลือกชุมนุมสำหรับนักเรียนระดับมัธยมศึกษาตอนต้นและตอนปลาย สำเร็จรูปสไตล์พรีเมียม พัฒนาด้วยเทคโนโลยีแบบ **Single Page Application (SPA)** ที่ทำงานได้รวดเร็วเป็นพิเศษบนเครื่องคอมพิวเตอร์และโทรศัพท์มือถือ โดยมีหลังบ้านเป็น **Supabase** ฟรีทีวี (Free Tier) ที่รองรับนักเรียนลงทะเบียนพร้อมกันกว่า **800 คน** ได้อย่างไร้รอยต่อ โดยไม่เกินข้อจำกัดการเชื่อมต่อ (Connection limits) และไม่เกิดการจองที่นั่งซ้ำซ้อน (Race Condition) 

---

## 🎨 จุดเด่นของระบบ (Key Features)

* **ดีไซน์พรีเมียมสีเขียวเอมเมอรัลด์ (Premium Emerald Glassmorphism):** หน้าเว็บตอบสนองรวดเร็ว ลื่นไหล มีเอฟเฟกต์สะท้อนแสง ทรานซิชันสวยงาม และรองรับการแสดงผลแบบ Responsive ในมือถือ 100%
* **ระบบตัวจับเวลาเปิด-ปิดอัตโนมัติ (Dynamic Live Countdown):** แสดงผลเวลาเปิดรับสมัครนับถอยหลังระดับมิลลิวินาที และเปิด/ปิดระบบให้ลงทะเบียนได้โดยอัตโนมัติโดยที่นักเรียนไม่ต้องกดรีเฟรชหน้าเว็บ
* **ระบบตัดยอดที่นั่งปลอดภัยสูงสุด (Row Lock Atomic Seats):** ใช้ฟังก์ชัน Stored Procedure บน PostgreSQL (`FOR UPDATE`) ในการล็อกที่นั่งก่อนเขียนทับ ทำให้มั่นใจว่าไม่มีทางเกิดปัญหา "ที่นั่งเรียนเกินโควตา" แม้จะยิงจองเข้ามาพร้อมกันในเสี้ยววินาทีเดียวกัน
* **ระบบสำรองสิทธิ์กรณีไม่มีชื่อ/เด็กใหม่/จำรหัสผ่านไม่ได้ (Forgot ID & Bypass Flow) 🆕:** สำหรับนักเรียนใหม่ ย้ายชั้นเรียน หรือนักเรียนเดิมที่จำเลขประจำตัวตนเองไม่ได้ สามารถคลิกปุ่มข้ามขั้นตอน `"ไม่มีเลขประจำตัว คลิกที่นี่"` เพื่อกรอกข้อมูล คำนำหน้าชื่อ ชื่อจริง นามสกุล และระดับชั้น เพื่อตัดโควตาสำรองสิทธิ์ที่นั่ง (สถานะ Pending) ทันทีอย่างสวยงามโดยไม่โดนตัวกรองรหัสนักเรียนบล็อก และครูแอดมินสามารถเข้ามาสืบค้นเลขนักเรียนจริงและอนุมัติสิทธิ์ (Verify) ภายหลังได้อย่างง่ายดาย
* **การบูรณาการคำนำหน้าชื่อตามมาตรฐานไทย (Title Prefix Integration) 🆕:** รองรับข้อมูลคำนำหน้าชื่อ (เด็กชาย, เด็กหญิง, นาย, นางสาว) ในระดับตารางฐานข้อมูลและหน้ารายงานผลทั้งหมด แสดงผลการรวมชื่อตามหลักไวยากรณ์ไทยอย่างเป็นทางการ (เช่น `นายสมชาย ใจดี` เขียนติดกันโดยไม่มีช่องว่างระหว่างคำนำหน้าและชื่อจริง) พร้อมระบบอัพโหลดแบบตรวจจับหัวตารางอัจฉริยะ (Header Detection Mapper) รองรับการนำเข้าไฟล์รายชื่อผ่าน Excel/CSV ทั้งแบบ 4 คอลัมน์เดิม และ 5 คอลัมน์ใหม่ได้อย่างปลอดภัย 100%
* **ระบบผู้ดูแลระบบอัจฉริยะ (Admin Dashboard):**
  * **รายงานสรุปเรียลไทม์:** รายงานสัดส่วนการจอง สถิติจำนวนที่นั่งของแต่ละชุมนุม
  * **ระบบอนุมัติเด็กใหม่:** แสดงตารางจัดการเด็กสมัครใหม่พร้อมกรอกรหัสและยืนยันตัวตน หรือสลับยกเลิกสิทธิ์
  * **จัดการชุมนุม:** ฟอร์มเพิ่ม ลบ หรือแก้ไขรายละเอียดชุมนุม ครูผู้สอน สถานที่เรียน โควตา และช่วงชั้นที่รับสมัคร (ม.1 - ม.6)
  * **ระบบ Bulk Import รายชื่อชุมนุม:** นำเข้ารายชื่อชุมนุมและโควตาทั้งหมดของโรงเรียนได้ในคลิกเดียวผ่านไฟล์ `.csv` 🆕
  * **ระบบ Bulk Import รายชื่อเด็ก:** นำเข้ารายชื่อนักเรียนเก่าได้เพียงลากและวางไฟล์ `.csv` ประมวลผลรวดเร็วผ่านคำสั่ง Upsert Batch
  * **ส่งออกเอกสาร Excel (Thai BOM CSV Export):** ส่งออกรายชื่อนักเรียนแยกตามชุมนุมหรือรวมทั้งโรงเรียนเป็นไฟล์ CSV ที่รองรับอักษรไทยสมบูรณ์แบบ เปิดใน Excel ภาษาไม่เพี้ยน ไม่เป็นตัวต่างดาว มีคอลัมน์คำนำหน้าชื่อแยกเรียบร้อย
  * **ระบบตรวจสอบประวัติย้อนหลังและความปลอดภัย (Audit Logs):** บันทึกการกระทำความปลอดภัยทั้งหมด (สมัครเรียนสำเร็จ, ลงสำรอง, ครูยืนยันสิทธิ์, ครูปฏิเสธ/ยกเลิกสิทธิ์, ครูตั้งค่าระบบ) พร้อมจับค่า **Public IP Address** และ **User Agent** ของผู้ทำคำสั่ง เพื่อป้องกันและตรวจสอบกรณีแกล้งกันได้อย่างสมบูรณ์แบบ 🆕

## 🚀 วิธีการติดตั้งและเปิดใช้งานออนไลน์ฟรีใน 3 นาที (ฉบับ No-Code ง่ายที่สุดในโลก 🌟)

หากคุณทำการโคลนโปรเจกต์นี้ไปใช้งานต่อเพื่อโรงเรียนของคุณ คุณสามารถตั้งค่าและเปิดใช้งานให้เป็นหน้าเว็บไซต์ออนไลน์จริงได้ทันที **ผ่านหน้าเว็บบราวเซอร์ของคุณเอง โดยไม่ต้องลงโปรแกรมหรือเขียนโค้ดแม้แต่นิดเดียว!**

> [!NOTE]
> กรุณาทำตาม 3 ขั้นตอนหลักด้านล่างนี้ตามลำดับ:

### 1️⃣ ขั้นตอนที่ 1: ตั้งค่าฐานข้อมูลหลังบ้าน (Supabase Setup)
1. สมัครสมาชิกหรือลงชื่อเข้าใช้งานที่ [Supabase](https://supabase.com) (ฟรี 100%)
2. กดปุ่ม **Create a new project** ตั้งชื่อโครงการและรหัสผ่านฐานข้อมูลให้เรียบร้อย (แนะนำให้เลือก Region เป็น **Singapore** เพื่อความรวดเร็วในการโหลดข้อมูลในประเทศไทย)
3. เมื่อสร้างโครงการเสร็จสมบูรณ์แล้ว ให้คลิกเมนู **SQL Editor** ที่แถบเครื่องมือซ้ายมือ (สัญลักษณ์รูป `SQL`)
4. คลิกปุ่ม **New Query**
5. คัดลอกเนื้อหาทั้งหมดจากไฟล์ [supabase/setup_database.sql](supabase/setup_database.sql) มาวางลงในกล่องข้อความ จากนั้นกดปุ่ม **Run** (สัญลักษณ์ปุ่มสีเขียวขวาล่าง)
6. **คัดลอกรหัสเชื่อมต่อ:** ไปที่เมนู **Settings** (รูปฟันเฟืองซ้ายล่าง) > **API** แล้วทำการคัดลอกค่า 2 ค่าต่อไปนี้เก็บไว้:
   * **Project URL** (เช่น `https://xxxxxx.supabase.co`)
   * **anon (public) Key** (รหัสคีย์สาธารณะขนาดยาว)

---

### 2️⃣ ขั้นตอนที่ 2: ตั้งค่าเชื่อมโยง API และเปิดใช้งานระบบ (มี 3 ทางเลือก - แนะนำวิธีที่ 1 เพื่อความปลอดภัยสูงสุด 🛡️)

> [!WARNING]
> **เรื่องสำคัญมากด้านความปลอดภัย:** การนำ **Project URL** และ **anon Key** ไปเขียนลงในไฟล์ `config.js` ตรง ๆ แล้วอัปโหลดขึ้น GitHub สาธารณะ (Public) จะทำให้รหัส API หลุดสู่สาธารณะและถูกสแกนเจาะข้อมูลได้! 
> 
> ดังนั้น เพื่อป้องกันรหัสผ่านหลุดและทำให้ระบบปลอดภัย 100% ขอแนะนำให้ใช้ **วิธีที่ 1** หรือ **วิธีที่ 2** ด้านล่างนี้ครับ:

---

#### 🔒 ทางเลือกที่ 1: ใช้ GitHub Secrets + GitHub Actions (แนะนำที่สุดสำหรับคลังเก็บโค้ดสาธารณะ 🌟)
ระบบของเราได้เตรียมไฟล์สั่งการอัตโนมัติ (Workflow) ไว้ให้แล้ว คุณสามารถฝากค่ากุญแจเชื่อมต่อไว้ในระบบความปลอดภัยของ GitHub (Secrets) โดย**ไม่ต้องแก้ไขไฟล์โค้ดใด ๆ ในโปรเจกต์เลย** ซึ่งมีขั้นตอนง่าย ๆ ดังนี้:

1. **ตั้งค่ารหัสลับใน GitHub (Secrets):**
   * ไปที่หน้าโปรเจกต์ของคุณบน GitHub -> คลิกแท็บ **Settings** (รูปฟันเฟืองด้านบนสุด)
   * ที่เมนูด้านซ้ายมือ เลื่อนลงมาที่หัวข้อ **Security** -> คลิกเลือก **Secrets and variables** -> เลือก **Actions**
   * คลิกปุ่มสีเขียว **New repository secret** (มุมขวาบน)
   * **สร้างคีย์ที่ 1:** ในช่อง Name ใส่ว่า `SUPABASE_URL` และในช่อง Value นำ **Project URL** ที่ได้จาก Supabase มาวาง แล้วกด **Add secret**
   * **สร้างคีย์ที่ 2:** คลิก **New repository secret** อีกครั้ง ในช่อง Name ใส่ว่า `SUPABASE_ANON_KEY` และในช่อง Value นำ **anon Key** จาก Supabase มาวาง แล้วกด **Add secret**

2. **เปิดสิทธิ์การใช้งาน GitHub Actions Deploy:**
   * ที่เมนูตั้งค่าซ้ายมือ คลิกหัวข้อ **Pages**
   * ในหัวข้อ **Build and deployment** -> ตรงช่อง **Source** ให้คลิกเลือกเปลี่ยนจาก `Deploy from a branch` เป็น **`GitHub Actions`** ⚙️

3. **เริ่มต้นใช้งานจริง:**
   * ไปที่แท็บเมนู **Actions** (แถบเมนูด้านบนของหน้าเว็บ)
   * คลิกเลือก Workflow ชื่อ **"Deploy to GitHub Pages"** ที่แถบเมนูด้านซ้าย
   * คลิกปุ่ม **Run workflow** -> เลือก Branch เป็น `main` แล้วกดปุ่มสีเขียว **Run workflow**
   * ระบบจะทำการสร้างหน้าเว็บความปลอดภัยสูงและอัปเดตลงลิงก์ GitHub Pages ให้คุณทันทีใน 1 นาที! ลิงก์เข้าใช้งานจะปรากฏอยู่บนหน้าจอครับ

---

#### 🔒 ทางเลือกที่ 2: เปลี่ยนเป็นคลังเก็บโค้ดส่วนตัว (Private Repository) + Deploy ผ่านผู้ให้บริการฟรี
หากต้องการความเป็นส่วนตัวสูงสุด ไม่อยากเปิดเผยหน้าซอร์สโค้ด และไม่มีทักษะด้านเทคนิคสูง:
1. ไปที่แท็บ **Settings** ของโปรเจกต์บน GitHub -> เลื่อนลงไปล่างสุดที่หัวข้อ **Danger Zone**
2. คลิกปุ่ม **Change visibility** แล้วเปลี่ยนเป็น **Private** (คลังเก็บโค้ดส่วนตัว - ฟรี 100%)
3. จากนั้นคุณสามารถเข้าไปแก้ไขไฟล์ **`config.js`** บนหน้าเว็บ GitHub เพื่อใส่รหัสเชื่อมต่อตามปกติได้ทันที โดยไม่มีบุคคลภายนอกมองเห็นไฟล์ของคุณได้เลย
4. **การ Deploy:** แนะนำให้ใช้ [Netlify](https://netlify.com) หรือ [Vercel](https://vercel.com) (สมัครฟรี 100%) เชื่อมต่อเข้ากับ GitHub Account ของคุณ แล้วเลือกดึงโปรเจกต์ส่วนตัวนี้ไปเปิดใช้งานแบบคลิกเดียวจบ!

---

#### ⚠️ ทางเลือกที่ 3: แก้ไขไฟล์ `config.js` ตรง ๆ บน GitHub (ง่ายที่สุด สำหรับทดสอบระบบ/ไม่ซีเรียสเรื่องกุญแจหลุด)
*ใช้ในกรณีที่คุณนำระบบไปรันเล่น ๆ หรือไม่มีข้อมูลสำคัญใด ๆ เท่านั้น:*
1. ไปที่หน้าแรกของคลังเก็บโค้ดบน GitHub คลิกเลือกเปิดไฟล์ชื่อ **`config.js`**
2. คลิกปุ่ม **รูปดินสอ ✏️ (Edit this file)** บริเวณมุมขวาบนของโค้ด เพื่อแก้ไขไฟล์ในบราวเซอร์ทันที
3. นำค่า **Project URL** และ **anon Key** มาวางแทนที่ในเครื่องหมายคำพูดคู่ `""` ของตัวแปร `SUPABASE_CONFIG` จากนั้นกดปุ่ม **Commit changes...** ด้านบนขวาเพื่อบันทึก
4. ไปที่ **Settings** > **Pages** -> เลือก Build from branch เป็น **`main`** แล้วกด **Save** เป็นอันเสร็จสิ้นครับ!

## 🔒 ข้อมูลความปลอดภัยของระบบผู้ดูแลระบบ (Admin Access)

* รหัสผ่านเริ่มต้นสำหรับเข้าใช้งานหน้าควบคุมแอดมินคือ: **`admin-password-1234`** (หากต้องการรันด้วยฐานข้อมูลค่าเริ่มต้นตามสคริปต์ SQL) หรือหากไม่ได้ตั้งค่าไว้ผ่านสคริปต์ รหัสสำรองฝั่งหน้าบ้านจะเป็น **`admin`**
* คุณครูสามารถเข้าไปแก้ไขรหัสผ่านควบคุมนี้ รวมถึงชื่อโรงเรียน ภาคเรียน/ปีการศึกษา และตั้ง วัน-เวลา เปิด/ปิดระบบรับสมัครเรียนแบบนับถอยหลังล่วงหน้าได้โดยตรงที่แท็บ **"ตั้งค่าเปิด-ปิดระบบ"** บนหน้าเว็บแอดมิน โดยไม่ต้องไปแก้ไขไฟล์โค้ดใด ๆ ทั้งสิ้น

## 💻 สำหรับผู้พัฒนาหรือการรันบนเครื่องส่วนตัว (Local Developer Run)

หากคุณเป็นนักพัฒนาและต้องการรันรหัสเพื่อทดสอบบนเครื่องคอมพิวเตอร์ของคุณเองก่อนการเผยแพร่:

**เปิดใช้งาน Web Server ในเครื่องส่วนตัว:**
เปิดโปรแกรม Terminal หรือ Command Prompt ในโฟลเดอร์โครงการของคุณ แล้วรันคำสั่ง:
```bash
python3 -m http.server 8080
```
จากนั้นเปิดบราวเซอร์แล้วไปที่ `http://localhost:8080` เพื่อทดลองใช้งานครับ!
